through text classification using **Transformers and LLMs**.

Explored and compared different language models,
including **Llama, Qwen, and DeepSeek**, through
fine-tuning and evaluation.

- 🥈 **2nd place at IberLEF 2025**
- 📄 Scientific publication in CEUR Workshop Proceedings
- 🔍 Model experimentation, fine-tuning, and evaluation

**Tech:** Python · PyTorch · Hugging Face · Transformers
